# 万歩計タウン 要件定義書

**バージョン**: 2.2
**日付**: 2026-08-08

---

## 1. 目的

実際の歩行データをゲームに変換し、体重・速度を考慮した「移動エネルギー」を蓄電池に蓄え、
その電気で夜の地球儀に灯りをともしていく放置ゲームを作る。

---

## 2. コアコンセプト

- 現実の歩行 → ゲーム内資源
  - 歩数 + 移動スピード + 体重 → 「移動エネルギー」を算出
  - エネルギーは蓄電池に蓄積
- 蓄電池 → まちの発展（地球の灯り）
  - 蓄電池が満タンになるとストックされ、まち画面で消費して電力を投入する
  - 投入するたびに発展度が上がり、真っ暗な地球儀に街明かりが少しずつ広がっていく
    （見た目は NASA Black Marble 夜間光画像を球面投影した地球儀。詳細は
    `ai-implementation-spec.md` 4.8 節）
- 放置ゲーム寄り
  - 歩くだけで自然にエネルギーが溜まる
  - プレイヤーは「満タン蓄電池をいつ投入するか」を楽しむ

---

## 3. 主要要件

### 3.1 入力・計算
- 体重・歩行速度・発電変換係数を設定可能
- スマホから歩数を取得（iOS: HealthKit / Android: ハードウェアセンサー）
- GPS による歩行速度の計測（設定画面）
- 移動エネルギーを計算し蓄電池に蓄積

### 3.2 まちの発展システム（地球の灯り）
- 蓄電池満タン分を消費して電力を投入する（現行UIは種類選択なしの単一操作）
- 発展度（投入回数の合計）に応じた発展段階表示（暗い地球→…→軌道から見た地球）
- 最終発展段階到達後はきらめきタイム演出
- 直近の投入からの経過時間できげんが変化
- まちに名前を付けられる

> 「げんきの素」「おもちゃ」による追加効果（蓄電池容量アップ・発電効率アップ）は
> 内部実装として残っているが、現行UIからは選択できず到達不能
（詳細は `ai-implementation-spec.md` 5.1 節）。

### 3.3 進行
- 日ごとの歩数・発電量記録（履歴画面）
- なつき度・愛着スコア
- 時間帯・天気・季節の背景演出（設定でオフ可）
- スクリーンショットモード（セッション限り）

### 3.4 非機能要件
- 完全にオフラインで動作
- データは端末内に保存（SharedPreferences）
- クリア条件なし（無限育成型）

---

## 4. スコープ

**実装済み**
- 体重・速度・発電係数の設定
- iOS / Android からの歩数取得
- エネルギー計算・蓄積・満タンストック
- 電力投入（単一操作）と発展度反映
- 発展段階（地球の灯り）・きげん・実績・履歴画面
- GPS 歩行速度計測

**将来検討**
- なでる以外のミニアクション（芸を見せる等）
- 難易度プリセット
- オンライン機能
- 「げんきの素」「おもちゃ」効果の UI 復活（`feedAuto` は未使用コードとして 2026-08-08 に削除済み）

---

## 5. 成功基準

- アプリをインストールして歩数を取得できる
- 歩行でエネルギーが蓄積し、満タン蓄電池で相棒が育つ
- データが端末に保存され、再起動後も残る
