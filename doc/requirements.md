# 万歩計タウン 要件定義書

**バージョン**: 2.1
**日付**: 2026-07-31

---

## 1. 目的

実際の歩行データをゲームに変換し、体重・速度を考慮した「移動エネルギー」を蓄電池に蓄え、
その電気で相棒を育てる放置・育成ゲームを作る。

---

## 2. コアコンセプト

- 現実の歩行 → ゲーム内資源
  - 歩数 + 移動スピード + 体重 → 「移動エネルギー」を算出
  - エネルギーは蓄電池に蓄積
- 蓄電池 → 相棒育成
  - 蓄電池が満タンになるとストックされ、相棒画面で消費してごはんを与える
  - ごはんの種類・効果により蓄電池容量や発電効率が向上する
- 放置ゲーム寄り
  - 歩くだけで自然にエネルギーが溜まる
  - プレイヤーは「満タン蓄電池をいつ相棒に与えるか」を楽しむ

---

## 3. 主要要件

### 3.1 入力・計算
- 体重・歩行速度・発電変換係数を設定可能
- スマホから歩数を取得（iOS: HealthKit / Android: ハードウェアセンサー）
- GPS による歩行速度の計測（設定画面）
- 移動エネルギーを計算し蓄電池に蓄積

### 3.2 相棒育成システム
- 蓄電池満タン分を消費してごはんを与える（ごはん・げんきの素・おもちゃ）
- ごはんには効果がある（蓄電池容量アップ、発電効率アップ）
- なつき度（給餌回数）に応じた進化段階表示
- 最終進化段階到達後はきらめきタイム演出
- 直近の給餌からの経過時間で相棒のきげんが変化
- 相棒に名前を付けられる

### 3.3 進行
- 日ごとの歩数・発電量記録（履歴画面）
- なつき度・愛着スコア
- 時間帯・天気・季節の背景演出（設定でオフ可）
- スクリーンショットモード（セッション限り）

### 3.4 非機能要件
- 完全にオフラインで動作
- データは端末内に保存（SharedPreferences）
- クリア条件なし（無限育成型）

---

## 4. スコープ

**実装済み**
- 体重・速度・発電係数の設定
- iOS / Android からの歩数取得
- エネルギー計算・蓄積・満タンストック
- 給餌（3種類）と効果反映
- 進化段階・きげん・実績・履歴画面
- GPS 歩行速度計測

**将来検討**
- なでる以外のミニアクション（芸を見せる等）
- 難易度プリセット
- オンライン機能

---

## 5. 成功基準

- アプリをインストールして歩数を取得できる
- 歩行でエネルギーが蓄積し、満タン蓄電池で相棒が育つ
- データが端末に保存され、再起動後も残る
