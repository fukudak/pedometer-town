# ストア掲載文（ドラフト）

## アプリ名
万歩計プラネット

## 短い説明（Google Play: 80文字以内）
歩いて発電し、夜の地球に灯りをともす万歩計アプリ

## 説明文（長文）

歩くだけで発電して、夜の地球に街の灯りをともそう。

「万歩計プラネット」は、毎日の歩数をエネルギーに変換し、そのエネルギーで夜の地球儀に街明かりを広げていく歩数連動の放置ゲームです。

【主な機能】
・歩数をエネルギー(Wh)に変換して蓄電池に蓄積
・満タンになった蓄電池をストックし、星画面で「投入」して地球の灯りを広げる
・発展度に応じて夜の地球儀の街明かりが段階的に増えていく（暗い地球 → 軌道から見た地球）
・地球儀は自転し、ドラッグで手動回転も可能
・GPSで実際の歩行速度を計測し、設定に反映
・過去の歩数・発電量の履歴を確認・削除可能
・体重・歩行速度・発電変換係数・星の名前をカスタマイズ

歩くモチベーションを、夜の地球を育てる時間に変えてみませんか？

【ご利用にあたって】
・歩数の取得には、iOSはHealthKit、Androidは歩数センサーを使用します
・位置情報は歩行速度の計測時のみ使用し、保存されません
・取得したデータは全て端末内に保存され、外部へ送信されることはありません
